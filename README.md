## Structure du dépôt

```
index.html   Le site complet (structure, styles et script)
photo.jpg    Ma photo de profil
README.md    Ce fichier
```

## Modifier le site

- **Textes en français** : directement dans `index.html`.
- **Textes en anglais** : dans l'objet `EN` du script, en bas de `index.html`. La clé correspond à l'attribut `data-i` de chaque élément.
- **Couleurs** : variables au début de la balise `<style>` (`--ac` pour le vert principal, `--dk` pour le vert foncé).
- **Photo** : remplacer `photo.jpg` par une autre image portant le même nom.
- **Liens des projets** : chercher l'adresse du projet dans `index.html` et la remplacer.

## Mettre le site en ligne

### Avec GitHub Pages

1. Déposer `index.html`, `photo.jpg` et `README.md` à la racine du dépôt.
2. Aller dans **Settings**, puis **Pages**.
3. Choisir la branche `main` et le dossier `/ (root)`, puis enregistrer.
4. Le site est disponible après une ou deux minutes à l'adresse `https://souranourah525-debug.github.io/<nom-du-depot>/`.

### Avec Vercel

1. Se connecter sur vercel.com avec GitHub.
2. Cliquer sur **Add New**, puis **Project**, et importer ce dépôt.
3. Valider sans rien changer : c'est un site statique.
